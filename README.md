# Bio Site White Label

Template mestre mobile-first em Next.js 16, React 19, TypeScript strict, Tailwind CSS 4, Lucide e Motion. A demonstração usa uma identidade fictícia de estética avançada.

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`. Para personalizar, comece por [CUSTOMIZATION_GUIDE.md](CUSTOMIZATION_GUIDE.md). Para validar:

```bash
npm run lint
npm run typecheck
npm run build
```

As fotografias de demonstração foram geradas para este projeto. Nenhum contato, credencial ou resultado profissional real é atribuído à pessoa fictícia.
